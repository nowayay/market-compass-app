# 🌍 MarketCompass

> AI-powered market expansion platform for international business analysis.

MarketCompass is a Progressive Web Application (PWA) that helps companies evaluate international expansion opportunities using Artificial Intelligence. The platform combines market analysis, company intelligence and AI-powered business consulting into one modern application.

This project is being developed as a Master's Thesis.

---

## ✨ Features

### 🤖 MarketCompassAI
An AI assistant powered by OpenAI GPT-5.5 specialized in:

- International expansion
- Market analysis
- Company research
- International trade
- Economics
- Business strategy
- Geopolitics
- Import & Export
- SWOT analysis
- PESTEL analysis

The assistant can also answer general questions similarly to ChatGPT.

---

### 📊 Company Analysis

Analyze companies by simply entering:

- Company name
- (Optional) Year of establishment
- (Optional) Company registration number (KRS)

MarketCompassAI automatically prepares:

- Company profile
- Industry overview
- SWOT analysis
- Market opportunities
- Expansion recommendations
- Country comparison
- Business risks

---

### 🌎 Expansion Dashboard

Interactive dashboard including:

- World market overview
- Market attractiveness score
- Country rankings
- Risk assessment
- Recommended expansion strategy

---

### 💬 AI Chat

ChatGPT-like interface featuring:

- Streaming responses
- Conversation history
- Markdown support
- Business-focused AI assistant

---

### 📱 Progressive Web App

- Installable on desktop and mobile
- Responsive design
- Fast loading
- Modern UI

# 🚀 Getting Started

## 1. Clone repository

```bash
git clone https://github.com/nowayay/MarketCompassApp.git
```

---

## 2. Open project

```bash
cd MarketCompassApp
```

---

## 3. Install dependencies

```bash
npm install
```

---

## 4. Create environment file

Create

```
.env.local
```

and add

```env
OPENAI_API_KEY=your_api_key_here
```

---

## 5. Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

# 📖 Purpose

The goal of MarketCompass is to simplify international expansion decisions for companies by leveraging Artificial Intelligence and publicly available business data.

The application aims to provide quick, structured and actionable recommendations for businesses considering entering new international markets.
